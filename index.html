Messaging platform migration

Private — NDA

Challenge

Our application depended on a third-party messaging platform that no longer met our operational and product requirements. The migration needed to preserve existing user data while minimizing service disruption for approximately 10,000 daily active users.

Solution

I contributed to the backend migration by designing and implementing the APIs required to transition to Firebase Realtime Database. To automate repetitive migration tasks, I also developed Python scripts that handled bulk data processing and reduced manual effort during the migration process. Throughout the rollout, I worked to maintain compatibility between the old and new systems to ensure a smooth transition.

NestJSTypeScriptPython Firebase Realtime DBPostgreSQLPrisma RabbitMQDockerKubernetes

Outcome

Migrated the messaging backend for roughly 10,000 daily active users with minimal service disruption, cut manual migration work through automated Python scripts, and left a more flexible foundation for future messaging features.

Financial accounting integration refactor

Private — NDA

Challenge

An existing financial workflow module needed to be refactored to support accounting integration across several high-volume transaction paths without disrupting core business operations. The main difficulty was modernizing the implementation while preserving reliability and keeping the logic maintainable for future changes.

Solution

I contributed to the backend refactor by restructuring the module into a more modular NestJS architecture, separating transaction processing into focused services for customer setup, item creation, journal entry generation, and workflow callbacks. The implementation used TypeScript, Prisma, and a service-oriented integration layer to connect financial events with the accounting system more cleanly and safely.

NestJS TypeScript Prisma PostgreSQL Docker

Outcome

The financial integration refactor improved the reliability, maintainability, and extensibility of the financial integration layer, making it easier to support new transaction flows and future reporting needs.

AmbulansKu — AI-powered Emergency Medical Access Platform

Vibathon Project Live Demo ↗ GitHub ↗

Challenge

Built during a Vibathon (AI-assisted hackathon), AmbulansKu addresses a critical problem in Indonesia by helping users quickly locate nearby ambulances and healthcare facilities for both emergency situations (e.g. accidents, heart attacks) and scheduled medical visits (e.g. dialysis and routine check-ups). The platform needed to understand natural Indonesian language and provide the fastest path to appropriate medical assistance.

Solution

Developed an AI-powered triage experience using the Vercel AI SDK and OpenRouter to interpret user requests in natural Indonesian language. Implemented geospatial facility search with PostGIS and Google Maps, enabling users to discover nearby ambulances and healthcare providers and contact them with a single tap. Built as a Progressive Web App (PWA) for mobile-first accessibility.

Next.js 16 TypeScript Vercel AI SDK OpenRouter Supabase PostGIS Google Maps API Tailwind CSS v4 shadcn/ui PWA Render

Outcome

Successfully delivered a functional MVP within the hackathon timeframe, demonstrating rapid product development, AI integration, geospatial search, and end-to-end deployment while validating an AI-assisted approach to emergency medical access.
